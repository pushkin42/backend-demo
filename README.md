# Демонстрационные модули для оценки качества кода.
## Не для продуктового использования!

**Ахтунг! Код не академический, модных курсов не заканчивал, пишу так чтобы решать боевые задачи, а не чтобы было "красиво"**

Данный репозиторий содержит демонстрационные обезличенные куски кода. Не пытайтесь использовать это в ваших проектах!

# Что тут есть

DTO - примеры Data transfer objects
Services - примеры сервисов
-  Parsers - примеры классов, работающих с CommerceML (разбор данных)
-  FileHashesCalculator - калькулятор хешей для изображений (используется в парсерах CommerceML)
-  Helpers - примеры универсальных классов для работы с данными


# Почему репозиторий загружен в один день?

Потому что раньше мне это было не нужно. Данные хранятся в приватных репозиториях и могут быть предоставлены по запросу.

# Почему код не "как в книжке"?

Потому что это код из реального проекта. Это не учебный пример «идеальной архитектуры», а рабочие сервисы для импорта CommerceML, обработки изображений, кеширования и синхронизации каталога. Некоторые решения сделаны исходя из ограничений продакшена, объёма данных и необходимости поддерживать старую базу.
