# Тестовое задание.

## Файлы
- ClubTestAction.php - обработчик для задания (можно использовать и Job, но тут задание выполняется не больше 2-3 секунд, поэтому в этом смысла нет)
- club-test.blade.php - blade шаблон для страницы
- club.css - CSS стили для страницы
- club.js - AlpineJS компонент для страницы
- routes.php - кусок web.php с маршрутами (можно использовать spatie/laravel-route-attributes и/или отдельный контроллер, но уровень задачи этого не требует)
